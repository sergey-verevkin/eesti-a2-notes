# Estonian A2 lesson notes

For transcript processing, use the `estonian-lesson-notes` skill installed locally as `estonian-lesson-notes`. Read it before creating notes. The current project template is `templates/lesson.md`.

Write explanations in Russian and examples in Estonian with Russian translations. Preserve chronological teaching stages. Homework is mandatory, even if the recording only permits a statement that it was not found. Separate additional examples from source material.

Keep raw inputs in their existing location. Put extracts and evidence in `.work/` (ignored by Git); only anonymized study material belongs in `lessons/`. Shared-chat summaries are reference context, not a substitute for the original recording. Do not publish to GitHub or send Telegram messages unless asked.

Raw input locations are provided locally by the user. Never modify source files or commit raw transcripts.
